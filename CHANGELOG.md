# Changelog

## 1.0.1

- Fix: регистронезависимая блокировка `.obsidian*` (Windows/macOS — регистронезависимые ФС).
- Fix: блокировка `.trash`, `.git`, `.smart-env` при санитайзинге пути.

- Fix: atomic `batch/write` делает безопасный бэкап (не теряет файл при откате).
- Fix: rate limit реально ограничивает все запросы, а не только неудачные авторизации.
- Fix: устранена утечка памяти в `_authFails` (периодическая очистка).
- Fix: `/health` отдаёт только `{"status":"ok"}` и не раскрывает метаданные.
