# REST API for Agents

Secure local REST API for AI agents and automation.

Плагин поднимает локальный HTTP-сервер, через который внешние агенты и скрипты
могут читать, писать, искать и управлять файлами в вашем хранилище Obsidian.

## Возможности

- Чтение и запись файлов (текст и бинарники)
- Batch-операции: read / write / delete / move
- Дерево файлов и папок
- Поиск по содержимому, пути, тегам, regex, fuzzy
- Backlinks / outlinks
- Метаданные файла: frontmatter, hash, mtime, mime

## Установка

1. Откройте Obsidian → Settings → Community plugins.
2. Найдите "REST API for Agents" и установите.
3. Включите плагин.

## Настройка

- **Токен** — генерируется автоматически. Храните его в секрете.
- **Порт** — по умолчанию `27125`.
- **Сеть** — по умолчанию сервер слушает только `127.0.0.1`.
- **Только чтение** — блокирует PUT/POST/DELETE.

## Безопасность

Все запросы кроме `/health` требуют заголовок:

    Authorization: Bearer <ваш-токен>

Сервер по умолчанию не выходит в локальную сеть. Токен — единственная
защита при включённом сетевом доступе. Не публикуйте порт в интернет.

## Платформы

Только desktop (Windows, macOS, Linux). На мобильных не работает,
так как используются Node.js модули `http`, `crypto`, `os`.
