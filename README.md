# REST API for Agents

Secure local REST API for AI agents and automation.

Плагин поднимает локальный HTTP-сервер внутри Obsidian, через который внешние агенты и скрипты могут читать, писать, искать и управлять файлами в вашем хранилище.

## Возможности

- Чтение и запись файлов (текст и бинарники)
- Batch-операции: read / write / delete / move (только для текстовых файлов)
- Дерево файлов и папок
- Поиск по содержимому, пути, тегам, regex, fuzzy
- Backlinks / outlinks
- Метаданные файла: frontmatter, hash, mtime, mime

## Установка

1. Откройте Obsidian → Settings → Community plugins.
2. Найдите "REST API for Agents" и установите.
3. Включите плагин.

## Настройка

- **Токен** — генерируется автоматически. Храните его в секрете.
- **Порт** — по умолчанию `27125`.
- **Сеть** — по умолчанию сервер слушает только `127.0.0.1`.
- **Только чтение** — блокирует PUT/POST/DELETE.
- **Максимальный размер файла** — по умолчанию 10 МБ. Применяется и к тексту, и к бинарникам.
- **Rate limit** — лимит запросов в минуту на один IP (по умолчанию 120).

## Безопасность

Все запросы кроме `/health` требуют заголовок:

    Authorization: Bearer <ваш-токен>

Модель угроз, ограничения и рекомендации описаны в [SECURITY.md](SECURITY.md).

Кратко:

- Сервер по умолчанию не выходит в локальную сеть.
- Публичный `/health` отдаёт только `{"status":"ok"}` — без метаданных.
- Пути `.obsidian*`, `.trash`, `.git`, `.smart-env` блокируются.
- Бинарные файлы в `batch/write` и `batch/move` не поддерживаются.
- Rate limit работает на всех запросах (не только на неверный токен).
- Audit log отсутствует. Все действия с vault не логируются.

## Платформы

Только desktop (Windows, macOS, Linux). На мобильных не работает, так как используются Node.js модули `http`, `crypto`, `os`.

## Ограничения

- `GET /tree?with_hash=1` читает все файлы vault. На больших хранилищах работает медленно.
- `GET /search?q=...` без ограничения по времени обходит все файлы. На больших vault может занять минуты.
- `minAppVersion: 1.0.0`.
